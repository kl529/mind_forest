# Mind Forest - 웹앱 전략

## 🌐 웹앱(PWA)으로 배포하기

스토어 등록 없이 웹앱으로 배포하는 전략입니다.

---

## ✅ 웹앱 배포의 장점

### 비용 & 시간
- **$0 비용**: 완전 무료
- **5분 배포**: 지금 바로 가능
- **즉시 업데이트**: 심사 대기 없음
- **무제한 사용자**: 비용 증가 없음 (트래픽 제한까지)

### 사용자 경험
- **링크만으로 접근**: 앱 설치 불필요
- **홈 화면 추가 가능**: 앱처럼 사용
- **자동 업데이트**: 사용자 액션 불필요
- **크로스 플랫폼**: 모든 디바이스 지원

### 개발자 경험
- **빠른 반복**: 코드 → 배포 1분
- **A/B 테스트 쉬움**: 즉시 변경 가능
- **분석 쉬움**: Google Analytics 등
- **SEO 가능**: 검색 엔진 노출

## 🚀 PWA 기능 추가하기

웹앱을 더욱 앱처럼 만들기:

### 1. **홈 화면 추가** (Add to Home Screen)
- 아이콘으로 설치
- 브라우저 UI 없이 실행
- 앱처럼 느껴짐

### 2. **오프라인 지원** (Service Worker)
- 인터넷 없이도 실행
- 빠른 로딩
- 네트워크 재개 시 자동 동기화

### 3. **푸시 알림** (제한적)
- Android: 완전 지원
- iOS: Safari 16.4+ 지원 (2023년부터)
- Desktop: 완전 지원

### 4. **앱 같은 UI**
- 풀스크린 모드
- 스플래시 스크린
- 상태바 스타일링

## 🔧 PWA 설정 파일 (Expo가 자동 생성)

Expo는 이미 PWA 기본 설정을 제공합니다:

### `app.json` - 이미 설정됨 ✅
```json
{
  "expo": {
    "name": "mind_forest",
    "icon": "./assets/images/icon.png",
    "splash": {
      "image": "./assets/images/splash-icon.png",
      "backgroundColor": "#ffffff"
    }
  }
}
```

### 웹 빌드 시 자동 생성되는 것들:
- ✅ `manifest.json` (앱 메타데이터)
- ✅ `icons` (다양한 크기)
- ✅ `service-worker.js` (기본 캐싱)

## 🎯 결론: 웹앱 먼저 추천!

### 왜 웹앱으로 시작해야 하나요?

1. **검증이 먼저**
   - 실제로 사람들이 사용하는지 확인
   - 비용 들이기 전에 수요 파악

2. **빠른 반복**
   - 피드백 → 개선 → 배포 (1시간 내)
   - 스토어는 심사 때마다 1-7일

3. **무료로 시작**
   - $0으로 1000명까지 가능
   - 검증 후 필요하면 스토어 진출

4. **나중에 전환 가능**
   - 웹앱에서 네이티브로 전환 쉬움
   - 같은 코드베이스 사용 (Expo)

### 언제 네이티브 앱으로 전환할까?

다음 조건을 만족하면 고려:
- ✅ 활성 사용자 100명 이상
- ✅ 일일 방문율 30% 이상
- ✅ 푸시 알림 등 네이티브 기능 필수
- ✅ 스토어에서 발견되길 원함
- ✅ 투자/수익화 계획 있음
