## 🚀 설정 단계

### Step 1: Supabase SQL 실행

Supabase 대시보드 (https://app.supabase.com)에서:

1. **SQL Editor** 클릭
2. **+ New query** 클릭
3. `SUPABASE_QUICK_START.md` 파일의 SQL 전체 복사
4. **Run** 버튼 클릭

### Step 2: 개발 서버 재시작

터미널에서:
```bash
# Ctrl+C로 서버 중지
npm start
```

## 🧪 테스트 방법

### 1. 회원가입/로그인

앱이 열리면 로그인 화면이 표시됩니다:
- **Email**: `test@mindforest.app` (기본값)
- **Password**: `testpassword123` (기본값)

**Sign In** 버튼 클릭:
- 계정이 없으면 → "Create Account?" 팝업 → **Create** 클릭
- 계정이 있으면 → 바로 홈 화면으로 이동

### 2. 기록 추가 (Entry 탭)

1. 하단 탭에서 **➕ Add** 탭 클릭
2. **😰 스트레스** 또는 **😌 스트레스 해소** 선택
3. 카테고리 선택 (신체적/정서적/행동적)
4. 반응 선택 (예: 불안, 산책 등)
5. 강도 선택 (1-5)
6. 메모 입력 (선택사항)
7. **Save Entry** 클릭

### 3. 캘린더에서 확인

1. 하단 탭에서 **📅 Calendar** 탭 클릭
2. 오늘 날짜에 색상이 표시되는지 확인
3. 오늘 날짜 클릭
4. 방금 추가한 기록이 모달에 표시되는지 확인

### 4. 여러 기록 추가

- 스트레스 기록 여러 개 추가 → 날짜가 빨간색으로 표시
- 스트레스 해소 기록 여러 개 추가 → 날짜가 파란색으로 표시
- 둘 다 추가 → 균형에 따라 색상 결정

## 📊 데이터 확인

### Supabase 대시보드에서 확인

1. **Table Editor** 클릭
2. **activity_entries** 테이블 선택
3. 추가한 기록들이 보이는지 확인

컬럼:
- `id`: UUID
- `user_id`: 사용자 ID
- `entry_type`: 'stress' 또는 'relief'
- `category`: 'physical', 'emotional', 'behavioral'
- `reaction`: 반응 이름
- `intensity`: 1-5
- `notes`: 메모
- `entry_date`: 날짜
- `created_at`: 생성 시간

## 🔍 문제 해결

### 로그인이 안 돼요
- `.env.local` 파일에 Supabase 키가 올바른지 확인
- 개발 서버를 재시작했는지 확인
- 브라우저 콘솔에서 에러 메시지 확인

### 기록이 저장 안 돼요
- Supabase SQL이 제대로 실행되었는지 확인
- `activity_entries` 테이블이 생성되었는지 확인
- RLS 정책이 활성화되었는지 확인

### 캘린더에 데이터가 안 보여요
- Entry 탭에서 먼저 기록을 추가했는지 확인
- 올바른 날짜에 기록했는지 확인
- 브라우저를 새로고침해보세요
