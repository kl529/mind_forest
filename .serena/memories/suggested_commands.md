# Suggested Development Commands

## Development Commands
- `npm install` - Install dependencies
- `npm start` / `npx expo start` - Start development server
- `npm run android` - Start on Android emulator
- `npm run ios` - Start on iOS simulator  
- `npm run web` - Start web development server

## Code Quality Commands
- `npm run lint` - Run ESLint for code quality checks
- `expo lint` - Alternative linting command

## Project Management
- `npm run reset-project` - Reset to blank project structure

## Testing and Development
- Use Expo Go app for device testing
- Use Android Studio emulator for Android testing
- Use iOS Simulator for iOS testing

## Git Commands (macOS/Darwin)
- `git status` - Check repository status
- `git add .` - Stage all changes
- `git commit -m "message"` - Commit changes
- `git push` - Push to remote repository

## macOS System Commands
- `ls -la` - List files and directories
- `cd <directory>` - Change directory
- `grep -r "pattern" .` - Search for patterns in files
- `find . -name "*.tsx"` - Find files by pattern
