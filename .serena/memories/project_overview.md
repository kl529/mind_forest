# Mind Forest - Stress Management App

## Project Purpose
Mind Forest is a stress management mobile app with terrarium visualization that helps users track stress levels and provides stress management recommendations. The app features:

- **Terrarium Visualization**: Visual representation that changes based on stress levels
- **Activity Tracking**: Log stress-inducing and stress-relieving activities
- **Calendar View**: Color-coded calendar showing daily stress levels
- **Statistics**: Monthly stress level trends with line graphs
- **Interactive UI**: Bottom navigation with Home, Calendar, and Statistics tabs

## Tech Stack
- **Framework**: Expo/React Native with TypeScript
- **Router**: Expo Router (file-based routing)
- **Navigation**: React Navigation (Bottom Tabs)
- **UI Components**: Custom themed components
- **Styling**: React Native StyleSheet
- **Language**: TypeScript with strict mode enabled
- **State Management**: React hooks (useState, useContext likely needed)
