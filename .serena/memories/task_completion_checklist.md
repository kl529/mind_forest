# Task Completion Checklist

When completing coding tasks in this project, ensure you:

## Code Quality Checks
1. **Run linting**: `npm run lint` - Fix any ESLint errors/warnings
2. **TypeScript compilation**: Ensure no TypeScript errors (check with IDE or tsc)
3. **Import organization**: Use relative imports and proper import structure
4. **Component structure**: Follow established patterns for components

## Testing and Validation  
1. **Start development server**: `npm start` and test functionality
2. **Cross-platform testing**: Test on web, iOS simulator, and Android emulator if possible
3. **Theme compatibility**: Ensure components work in both light and dark themes
4. **Navigation flow**: Verify navigation between screens works correctly

## Code Standards
1. **TypeScript strict mode**: No `any` types, proper type definitions
2. **Component patterns**: Follow existing ThemedView/ThemedText patterns
3. **File organization**: Place files in appropriate directories
4. **Naming conventions**: PascalCase for components, camelCase for variables

## Final Steps
1. **Test key user flows**: Main navigation, input screens, data persistence
2. **Performance check**: Ensure smooth animations and transitions
3. **Accessibility**: Basic accessibility considerations for mobile users
4. **Code cleanup**: Remove console.logs, unused imports, commented code
